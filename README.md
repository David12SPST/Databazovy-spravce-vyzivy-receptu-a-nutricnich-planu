# Databazovy-spravce-vyzivy-receptu-a-nutricnich-planu
Vytvořte v prostředí Visual Studio (jazyk C#) desktopovou aplikaci pro Windows Forms s verzováním na GitHubu. Aplikace bude sloužit k evidenci potravin, sestavování vlastních receptů a plánování denního jídelníčku.

Klíčovým požadavkem je dodání aplikace spolu s funkční výchozí databází. Součástí výchozích dat musí být minimálně 20 detailně zadaných základních surovin rozdělených do kategorií (maso, pečivo, zelenina, ovoce, mléčné výrobky, tuky apod.) s reálnými nutričními hodnotami na 100 g (kalorie, bílkoviny, sacharidy, tuky, vláknina, alergeny) a minimálně 5 kompletních vzorových receptů složených z těchto surovin.

Uživatel bude moci databázi dále rozšiřovat (CRUD operace), filtrovat, tvořit denní jídelníčky a sledovat plnění cílových hodnot pomocí vizuálních ukazatelů (např. stylizovaných ProgressBarů, barevných indikátorů nebo GDI+). Veškerá data se budou ukládat a načítat ze strukturovaných souborů ve formátu JSON nebo XML.
